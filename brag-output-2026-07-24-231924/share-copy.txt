MEDIUM (LinkedIn / Show HN)

I kept losing good questions inside long chats — ask the aside, and the
main thread is derailed; don't, and the question's gone.

So I built Branch: a desktop chat client where a conversation is a tree,
not a line.

• Highlight any phrase and branch a side-conversation off it — the main
  thread stays exactly where it was.
• The whole conversation lives on one canvas, with a minimap — every
  branch its own colour and its own dash pattern, never colour alone.
• Ask one question to three models at once (claude-opus-4-8, gpt-5,
  gemma3:4b) — each answer is its own branch, side by side.
• Diff two branches to see exactly where they disagree.
• Siblings share a cached prompt prefix (Anthropic), so the next branch
  costs a fraction of the first.
• No API key required: point it at a local model (gemma3:4b via Ollama)
  and nothing leaves your machine — refresh the list anytime.
• Full-text search across every message (⌘K), export a thread or the
  whole tree, and clip any excerpt straight into per-session notes.

Built with pywebview + a Python backend and a React/Tailwind front end.

Your conversation is a tree, not a line.
